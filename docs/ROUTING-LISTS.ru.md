# Правила маршрутизации: категории GeoSite/GeoIP, домены и IP

В M-UI Fusion откройте **Настройки Mihomo → Правила маршрутизации → Добавить правило**.

В поле **Тип правила** выберите **Списки категорий, доменов и IP**. Редактор покажет два высоких поля.

## GeoSite/GeoIP

По одной категории на строку: `youtube`, `category-ru`, `ru`. Список категорий берётся **из уже установленных файлов** `GeoSite.dat` и `GeoIP.dat` в каталоге данных M-UI, не из списка по умолчанию и не из внешнего сайта.

Нажмите **Выбрать из списка** — откроется окно с поиском, фильтром GeoSite/GeoIP и кнопкой **Добавить** напротив каждой категории. Если название встречается в обеих базах, уточните тип: `geosite:google` либо `geoip:google`. Такие префиксы также устанавливаются автоматически при выборе из окна.

Без установленного файла категория не предлагается. Несуществующие или неоднозначные категории не сохраняются.

## Домены и IP

По одному элементу на строку:

- `example.com` — домен и его поддомены (Mihomo DOMAIN-SUFFIX)
- `full:api.example.com` — только точный домен (DOMAIN)
- `192.0.2.0/24` — подсеть IPv4 (IP-CIDR)
- `192.0.2.7` — один IPv4 (эквивалент /32)
- `2001:db8::/32` — подсеть IPv6 (IP-CIDR6)
- `2001:db8::1` — один IPv6 (эквивалент /128)

Оба поля можно использовать одновременно. **Любое совпадение** с категорией, доменом или IP отправляется в **один выбранный исходящий**. Это логика **ИЛИ** (OR), а не AND.

M-UI создаёт одно обычное правило Mihomo со встроенным логическим выражением AND(OR(...)). Оно остаётся на своём месте в таблице, не нарушает порядок правил и не меняет конфигурацию до нажатия «Сохранить» и применения в Mihomo. Проверка `no-resolve` применяется к IP-условиям внутри выражения.

В редакторе старых сложных правил AND сохраняется **расширенный режим** с исходным выражением. Они не конвертируются автоматически в новый формат и не переписываются при простом открытии.

Внизу таблицы остаётся единственное завершающее правило MATCH, как и прежде.

**Безопасность:** перед обновлением M-UI делайте копии `state.json`, `config.yaml` и бинарного файла; новые правила сначала проверяйте на тестовом конфиге Mihomo, а затем на реальном трафике.
