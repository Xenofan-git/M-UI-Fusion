# Балансировщики и подписки в M-UI Fusion

Начиная с версии **v0.3.3-sniffer.3**, балансировщики отделены от списка отдельных узлов.

## Где находятся

- **Outbounds** (Mihomo Settings → Outbounds): отдельные прокси-узлы, в том числе импортированные подписками. Группы здесь больше не отображаются.
- **Балансировщики**: единая вкладка для ручных групп и подписок только внутри **Mihomo Settings → Балансировщики** (отдельного пункта бокового меню нет). Здесь создаются и редактируются группы.
- **Подписки**: источники VPN-узлов, их URL, интервалы автоматического обновления и последние результаты.

## Как добавить подписки в балансировщик

1. Сначала добавьте URL в разделе **Подписки** и дождитесь успешного импорта узлов в Outbounds.
2. Перейдите в **Mihomo Settings → Балансировщики**, откройте существующую группу или нажмите **Добавить балансировщик**.
3. Для обычного ручного балансировщика нажмите **«Добавить балансировщик»**. Для новой URL-подписки нажмите **«Добавить балансировщик из подписки»**, укажите URL и название группы, загрузите серверы, примените фильтры **«Оставить только»** и **«Исключить»**, при необходимости исключите отдельные узлы и настройте интервал автообновления. Выберите тип: **URL Test** (самый быстрый доступный узел), **Fallback** (приоритет по порядку), **Load Balance** (распределение запросов) либо **Select** (ручной выбор).
4. В поле **Подписки (все узлы автоматически)** выберите **один или несколько источников**. Можно одновременно оставить выбранные вручную прокси-узлы из списка Members.
5. Сохраните изменения группы и нажмите **Save** в верхней части Mihomo Settings. Перезапустите Mihomo, если панель попросит применить изменения.

Готовая группа становится обычной целью маршрутизации и доступна в **Routing Rules**. Порядок правил и текущие системные маршруты Linux не меняются автоматически.

## Автоматическая синхронизация

При очередном обновлении источника все **новые узлы** добавляются во все подключённые к нему группы. Узлы, удалённые провайдером, убираются из этих групп. Узлы других подписок и ручные участники не затрагиваются. Порядок существующих членов сохраняется; новые добавляются в порядке получения.

Если источник недоступен, пуст или изменился так, что группа останется без участников, обновление отклоняется и действующая конфигурация сохраняется. Прежде чем применять обновление, панель проверяет YAML через установленный Mihomo.

**Подписку можно подключить к нескольким балансировщикам, а в один балансировщик — несколько подписок.** Источник, подключённый ранее через поле «Балансировщик» в карточке подписки, продолжит работать; новые привязки удобнее делать в разделе «Балансировщики».

## Переход со старых версий

Существующие группы из Outbounds **не удаляются и не пересоздаются**, а только меняют место отображения. Их имена, выбранные участники, типы балансировки, параметры проверок и ссылки в Routing Rules остаются прежними.

Файлы данных продолжают храниться в защищённом state.json. Идентификаторы выбранных подписок сохраняются у каждой группы в поле subscriptionIds; в сгенерированный Mihomo YAML попадают обычные имена участников группы, без служебных метаданных.

Перед обновлением панели сохраните исходный бинарник и конфигурацию. См. [универсальную SSH-инструкцию](INSTALL.ru.md).


### Флаги и выбор серверов

В списке серверов название показывается целиком в одной строке; длинные строки можно прокручивать горизонтально или прочитать по наведению. Флаг определяется по названию сервера (явное эмодзи, двухбуквенный код либо название страны на русском/английском), а не по GeoIP.
Рядом с полями **«Оставить только»** и **«Исключить»** кнопка **«🏳️ Добавить флаг»** позволяет выбрать страну из каталога ISO 3166. Фильтры понимают флаг и название страны как эквивалентные записи — например 🇨🇭 находит узлы с названием «Швейцария». Исходное имя узла не изменяется при предпросмотре.
Интервал автообновления для новых подписок по умолчанию **1440 минут (24 часа)**. Ранее настроенные интервалы остаются без изменений.


### Отображение флагов в Windows

Флаги серверов и стран в фильтрах отображаются **локальными SVG-изображениями** (каталог ISO 3166). Это не зависит от шрифтов Windows и не требует загрузки с внешнего CDN. При выборе флага в «Оставить только» или «Исключить» записывается название страны (например Switzerland) и рядом отображается цветной SVG-флаг. Фильтры, сохранённые ранее с эмодзи 🇨🇭, продолжают работать и визуально распознаются как выбранная страна. Атрибуция графики: web/flags/LICENSE.txt (flag-icons, MIT).
