# Входящие URL-подписки на VPN-узлы в M-UI Fusion

В отличие от раздела *Subscription Templates* (выдача клиентских подписок), новый раздел **«Подписки»** служит для **получения узлов от внешних VPN-провайдеров**.

## Работа в панели

1. Откройте панель, выберите в боковом меню **«Подписки»** и нажмите **«Добавить подписку»**.
2. Введите имя и URL подписки. Поддерживаются Mihomo/Clash YAML с секцией proxies, обычные многострочные VLESS, VMess, Trojan, Shadowsocks и другие ссылки поддерживаемых типов, а также Base64-кодированные списки ссылок.
3. Укажите интервал обновления **5–10080 минут** (по умолчанию 60) и, если нужно, существующую группу через настройки подписки. Для подключения **нескольких подписок к одной группе** используйте отдельную вкладку **«Балансировщики»**.
4. После нажатия **«Сохранить и импортировать»** все распознанные прокси-узлы автоматически добавятся в **Outbounds**. В карточке источника появятся количество узлов и дата последнего обновления.
5. Автообновление проверяет подписку по заданному интервалу. **«Обновить»** запускает ручное обновление, а **«Изменить»** позволяет сменить URL, интервал, имя и группу.

## Правила безопасного обновления

- Каждый импортированный Outbound хранит ID своей подписки. Ручные узлы не удаляются и не перезаписываются обновлениями.
- При обновлении сохраняется ID узла с тем же именем, а его параметры обновляются. Новые узлы добавляются, устаревшие удаляются, а участники **всех связанных балансировщиков** синхронизируются.
- Пустой, недоступный или несовместимый список **не удаляет** ранее работавшие узлы. Если удаляемый узел используется в правиле или его удаление оставит группу без участников, обновление отклоняется.
- Сохранение Mihomo Settings со старой открытой вкладки не может затереть узлы, обновлённые подпиской: потребуется обновить страницу.
- URL с токенами сохраняются в защищённом state.json. Не публикуйте state.json, ссылки с токенами и резервные копии в GitHub.
- URL не может обращаться к loopback, частной или служебной сети; загрузка ограничена 2 МБ / 2000 узлов. HTTPS предпочтителен, HTTP-переадресации на внутренние IP блокируются.
- Mihomo перезапускается после успешного изменения Outbounds, чтобы применить конфигурацию. Для постоянных подключений выбирайте умеренный интервал.
- **Существующие ручные узлы не конвертируются в подписочные автоматически.** Их можно сохранить или удалить отдельно после проверки новых узлов.

## Проверка на Linux

После установки новой версии выполните на своём сервере:

    sudo systemctl is-active m-ui
    sudo /usr/local/m-ui/m-ui version
    sudo journalctl -u m-ui -n 35 --no-pager

Планировщик встроен в m-ui. Отдельные cron-задания, watcher-сервисы и ручное редактирование config.yaml не нужны. Системный сетевой маршрут Linux не изменяется.

Подробнее о нескольких подписках в группе и выделенной вкладке: [Балансировщики](BALANCERS.ru.md).
