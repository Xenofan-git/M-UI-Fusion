# M-UI Fusion 1.0.2 — Russian localization repairs / Исправление русского перевода

## English

This maintenance release fixes **630 of the 925 Russian translation entries** reviewed in M-UI Fusion, including previously incorrect machine translations.

- **Dashboard:** the CPU caption now reads "ЦП: 4 ядра" on a four-core machine, with correct Russian singular/plural forms for other core counts; memory, disk, log, uptime and traffic labels are improved.
- **Controls and safety:** corrected Save, Cancel, Delete, Start, Stop, Refresh and confirmations. Fixed potentially misleading descriptions for panel restart, state restoration, TLS certificates and client quotas.
- **Mihomo:** improved outbound, balancer, routing-rule, subscription and connection labels. Previously approved Balancers column labels **Источник / Тест / Настройки** remain unchanged.
- **Advanced protocols:** repaired explanatory text for Shadowsocks, Snell, TLSMirror, QUIC, TrustTunnel, Sudoku, Hysteria2 rendezvous, WARP, VPNGate and other settings, retaining technical names and meaning.
- **Multi-control:** improved status messages, synchronization feedback and cross-panel subscription wording.
- Four glaring CPU captions were also repaired in Turkish, Persian, Vietnamese and Spanish.
- Added regression checks for the 925-key Russian catalog, interpolation placeholders, correct CPU plurals and important operational messages.

**No configuration migration:** This patch changes front-end localization and display-only CPU grammar. It does not modify routing rules, inbound/outbound data, VPN subscriptions, proxy credentials, traffic accounting, Tailscale, or firewall settings.

The first official v1.0.0 release and v1.0.1 balancer-warning release remain available with their original notes.

For an existing installation, back up m-ui, state.json and config.yaml and then update to v1.0.2 using the project installer.

## Русский

В этой версии исправлены **630 из 925 проверенных строк русской локализации** M-UI Fusion. Основная причина ошибок — некачественный машинный перевод.

- **Главная панель:** вместо «CPU: 4 Коры» теперь отображается **«ЦП: 4 ядра»**. Добавлено правильное склонение для 1, 2, 4, 5 и других чисел. Исправлены подписи памяти, диска, журналов, времени работы и трафика.
- **Кнопки и предупреждения:** «Спасти» заменено на «Сохранить», «Логс» — на «Журналы», «инвалид» — на «Отключено» и так далее. Исправлены описания перезапуска, удаления, резервного копирования и восстановления.
- **Mihomo:** исправлены подписи исходящих, балансировщиков, правил, подписок и соединений. Ранее утверждённые названия столбцов **«Источник», «Тест», «Настройки»** сохранены.
- **Протоколы:** заново переведены некорректные технические пояснения для Shadowsocks, Snell, TLSMirror, QUIC, TrustTunnel, Sudoku, Hysteria2 rendezvous, WARP, VPNGate и других настроек. Имена полей и протоколов не изменялись.
- **Multi-control:** исправлены сообщения синхронизации, статусы устройств и названия межпанельных подписок.
- Исправлены очевидно неправильные подписи CPU на турецком, персидском, вьетнамском и испанском языках.
- Добавлены тесты проверки всех 925 русских ключей, подстановок переменных и склонения слова «ядро».

**Сетевые настройки не меняются.** Обновление касается только текста интерфейса и склонения подписи процессора. Балансировщики, правила, подписки, ключи, конфигурация Mihomo, Tailscale и Keenetic остаются неизменными.

Версии 1.0.0 и 1.0.1 сохраняются в истории релизов.

Перед обновлением необходимо создать резервные копии m-ui, state.json и config.yaml.
