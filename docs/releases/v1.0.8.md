# M-UI Fusion 1.0.8 — Readable Apply buttons / Кнопка «Применить» без затемнения

## English

This update fixes an unreadable **Apply to Draft** button on hover in the Mihomo routing rule editor, and simplifies its caption. It does not modify the Mihomo engine, routing rules, subscriptions, settings, credentials or network.

- The action is now called **Apply** in the routing and outbound editors. The same short action has been localized for all **11 supported languages**. The old term "draft" was confusing in a button.
- **Apply** updates the configuration **pending on the Mihomo settings page**. The existing top-level **Save** button is still required to persist the changes. This two-step save mechanism remains unchanged.
- Both the routing rule and outbound modal buttons have a stable, opaque accent fill and a readable matching foreground on default, hovered, focused and pressed states. The selected color skin is preserved. This also covers the VPNGate modal's primary footer button.
- Styles are targeted to the Mihomo modals only, preventing conflicts with global Liquid Glass, shadcn and Material 3 rules. The fix applies in light and dark mode with or without a selected palette.
- **270 real Chromium checks**: three dialogs × three states × five palettes × three theme layouts × two light/dark modes. Minimum measured text contrast **5.01:1** (WCAG AA).
- New static CI tests check the button captions, all supported locales and CSS/cache version updates. Assets for colors, the Mihomo JavaScript and translations are cache-busted as ?v=108.

Older releases remain available. No configuration migration or network changes are made.

## Русский

Исправлена тёмная кнопка **«Применить к черновику»** при наведении на неё в редакторе правил Mihomo, и убрана путаная подпись. Движок Mihomo и работающая конфигурация не меняются.

- Кнопка теперь называется **«Применить»** в редакторах правил и исходящих. Краткий перевод обновлён для **всех 11 языков** панели.
- При нажатии **«Применить»** правило попадает в текущие **несохранённые изменения страницы**. Для окончательной записи в конфигурацию Mihomo, как и раньше, требуется отдельная кнопка **«Сохранить»** на основной странице. Логика сохранения не меняется.
- В редакторах правил и исходящих, а также в окне VPNGate, основные кнопки получают **непрозрачный акцентный фон и контрастный текст** в обычном состоянии, при наведении, фокусе и нажатии. Цветовая тема пользователя сохраняется.
- Стили ограничены только соответствующими модальными окнами и не затрагивают другие кнопки Liquid Glass, shadcn и Material 3.
- **270 проверок в Chromium**: три окна, три состояния, пять палитр, три оформления, светлая и тёмная темы. Минимальная контрастность текста — **5,01:1**, что соответствует WCAG AA.
- Добавлены тесты CI для надписей и стилей. JS/CSS/переводы обновляются в браузере с ?v=108, чтобы не использовать устаревшие файлы из кэша.

Все предыдущие релизы сохраняются. Правила маршрутизации, балансировщики, подписки, ключи, DNS, firewall и Tailscale не меняются.
