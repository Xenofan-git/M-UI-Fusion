# M-UI Fusion v1.0.9 — Russian explanations for rule types / Понятные названия типов правил

## English

A **display-only** update to Mihomo routing rules, keeping all underlying rules and the Mihomo core unchanged.

- In Russian, technical MATCH is now displayed as **«ВЕСЬ ОСТАЛЬНОЙ ТРАФИК»** in the rule table and the rule editor. The actual stored type remains MATCH, still must be last and cannot be deleted, moved or converted into another type. Its outbound remains editable.
- Every other supported Mihomo rule type shows its original technical name followed by an accessible Russian explanation, separated by a dash (for example **GEOIP — Страна IP назначения**, **GEOSITE — Категория сайтов GeoSite**, **PROCESS-NAME — Имя программы**, **NETWORK — Сетевой протокол TCP или UDP**). This applies to the type dropdown, existing rule rows and managed rule rows.
- The list-based editor remains available under **«СПИСКИ КАТЕГОРИЙ, ДОМЕНОВ И IP — Несколько условий»** in Russian.
- The Russian rule-order note, the no-conditions message for MATCH and the protected-rule warning also use the human-readable label.
- Other languages continue to display the exact Mihomo type codes; switching the UI language updates labels **without changing the option values, selected rule, saved state or rendered YAML**.
- Existing ! tooltips continue to provide more detailed explanations, including for the fallback rule.
- Added unit tests for all **33** Mihomo native rule types and real Chromium desktop/mobile tests for rule-editor values, Russian labels and switching Russian/English. Browser JS and translation resources use ?v=109 for fresh loading.

No changes to engine, routing rules, subscriptions, outbounds, balancing, authentication, DNS, Tailscale, or firewall.

## Русский

**Только изменение отображения** типов правил Mihomo, без изменения движка и работающей маршрутизации.

- Технический MATCH во вкладке правил и окне редактирования теперь называется **«ВЕСЬ ОСТАЛЬНОЙ ТРАФИК»**. В конфигурации он по-прежнему MATCH, всегда находится последним и защищён от удаления и изменения типа. Изменять его исходящий можно.
- Напротив остальных типов через тире добавлена краткая понятная расшифровка по-русски. Примеры: **GEOIP — Страна IP назначения**, **GEOSITE — Категория сайтов GeoSite**, **PROCESS-NAME — Имя программы**, **AND — Все вложенные условия одновременно**, **NETWORK — Сетевой протокол TCP или UDP**. Подписи действуют и в выпадающем списке, и в таблице правил.
- Тип списков теперь отображается как **«СПИСКИ КАТЕГОРИЙ, ДОМЕНОВ И IP — Несколько условий»**.
- В русской подсказке о порядке правил, сообщении об отсутствии условий и предупреждении о защите завершающего правила используется новое понятное название.
- В других языках остаются технические названия. Переключение языка меняет исключительно текст, не меняет option.value, выбранный тип, исходящий, правила и их выражения.
- Значки ! с подробными пояснениями остаются.
- Добавлены тесты всех **33** типов правил и браузерные тесты Chromium на компьютере и узком экране. Версии JS/переводов в браузере обновлены до ?v=109.

Движок Mihomo, работающие правила, GEOIP/RU, No-Resolve, балансировщики и параметры сети не меняются.
