# M-UI Fusion 1.0.6 — Expandable routing rule settings / Исправление раскрытия расширенных настроек

## English

This maintenance update fixes the **Advanced settings** accordion in the Mihomo routing rule editor.

- Previously, JavaScript forcibly reopened the section when editing GEOIP, IP-CIDR, MATCH and other advanced rule types. The contents also used a CSS grid declaration that could override the native closed state of the HTML details element.
- The section now starts **collapsed** for every rule type, including existing GEOIP,RU rules. Clicking or using the keyboard on Advanced settings opens or closes it normally, and the contents are visually hidden when closed.
- The **rule type**, **expression** (e.g. RU), and no-resolve checkbox stay unchanged while expanding and collapsing; no routing rule is implicitly saved or modified.
- Retained the native HTML details/summary mechanism for browser keyboard accessibility. No new library required.
- Added small ! help icons beside each of the **33 rule types** in the routing table and beside No-Resolve. Hover, click or keyboard focus opens a framed tooltip explaining the condition. The shared tooltip is not clipped by the scrollable table or modal.
- The editor's **No-Resolve** checkbox now has a short help icon and a clear explanation: this option suppresses extra DNS lookups solely for an IP-based rule; it does not disable DNS globally.
- The rule type selector displays **СПИСКИ КАТЕГОРИЙ, ДОМЕНОВ И IP** in uppercase (and **СПИСКИ** in the rule table), consistent with other rule type labels.
- JavaScript, CSS and translation assets are cache-busted with ?v=106a.
- Static UI checks plus **14 real Chromium checks** on desktop and mobile viewports cover GEOIP, new list rules and MATCH, ensuring open/close/reopen, preserved expression and checkbox state, and no forced reopening on form synchronization.

**No migration or configuration change.** Routes, balancers, subscriptions, credentials, state.json, config.yaml and Mihomo are not changed by this patch. All earlier releases remain available.

## Русский

Обновление исправляет сворачивание и раскрытие раздела **«Расширенные настройки»** при редактировании правил маршрутизации Mihomo.

- Ранее JavaScript принудительно возвращал раздел в раскрытое состояние для GEOIP, IP-CIDR, MATCH и других типов. Дополнительно CSS-сетка могла показывать содержимое даже после сворачивания.
- Теперь раздел по умолчанию **свёрнут** для любого типа правила, в том числе существующего GEOIP,RU. Нажатие на «Расширенные настройки» нормально раскрывает и сворачивает поля.
- **Тип правила**, **выражение** (например, RU) и галочка no-resolve сохраняют свои значения при открытии и закрытии. Никакие правила самопроизвольно не изменяются и не сохраняются.
- Сохранён штатный механизм HTML details/summary и управление с клавиатуры.
- В колонке **«Тип правила»** рядом с каждым из **33 типов** добавлен маленький значок **!**. При наведении, нажатии или фокусе с клавиатуры появляется подсказка в рамке с объяснением конкретного правила.
- Рядом с параметром **No-Resolve** в редакторе и таблице есть такой же знак **!**: пояснение рассказывает, что опция запрещает дополнительное DNS-разрешение ради проверки IP-правила, но не отключает DNS целиком.
- Название в списке типов **«СПИСКИ КАТЕГОРИЙ, ДОМЕНОВ И IP»** теперь набрано заглавными буквами, как и другие типы. В таблице — «СПИСКИ».
- Для обновления кэша браузера JS, CSS и переводы подключаются с параметром ?v=106a.
- Добавлены тесты интерфейса; **14 проверок в Chromium** для настольного и мобильного экрана подтвердили открытие, закрытие и сохранение значений для GEOIP, списков и MATCH.

**Только исправление интерфейса.** Подписки, маршруты, балансировщики, ключи и файлы конфигурации Mihomo не меняются. Все прежние релизы сохранены.
