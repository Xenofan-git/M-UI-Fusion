# M-UI Fusion 1.0.1 — Clear balancer deletion warnings / Понятные предупреждения при удалении балансировщиков

## English

**What changed**
- When a balancer is used by routing rules, the Delete button now opens a centered, theme-aware warning dialog instead of an unreadable toast.
- The dialog names the balancer and lists **all** routing rules that reference it (for example, AND → Russia and GEOIP → Russia).
- **Got it** closes the warning without changing anything. **Go to routing rules** opens the rules tab, highlights the dependent rules, and focuses the edit action.
- An orange warning icon, keyboard focus handling, Escape-to-dismiss, and responsive sizing are included. Translations are available for all 11 panel languages.

**Safety:** No routing rule, balancer, subscription, proxy, or credential is removed or rewritten by the warning. Existing restrictions against deleting a referenced balancer remain in place.

**Upgrade:** Back up your current state.json, config.yaml, and m-ui binary. Use the fork-specific install/update guide with --update --version v1.0.1.

## Русский

**Что изменилось**
- При попытке удалить балансировщик, используемый правилами маршрутизации, вместо непонятного уведомления появляется аккуратное окно предупреждения по центру экрана.
- В окне указаны название балансировщика и **все** связанные правила (например, AND → Russia и GEOIP → Russia).
- Кнопка **«Понятно»** закрывает окно без изменений. Кнопка **«Перейти к правилам»** открывает вкладку маршрутизации, подсвечивает связанные строки и переводит фокус на редактирование.
- Добавлены оранжевый знак предупреждения, управление с клавиатуры, закрытие по Escape и адаптация для телефонов. Переводы доступны для всех 11 языков панели.

**Безопасность:** Предупреждение не удаляет и не изменяет правила, балансировщики, подписки, прокси, пароли и ключи. Защита от удаления используемого балансировщика сохранена.

**Обновление:** Перед обновлением сохраните копии state.json, config.yaml и бинарника m-ui. Используйте инструкцию SSH-обновления с параметрами --update --version v1.0.1.

Первая официальная версия **1.0.0** остаётся отдельным выпуском со своей полной историей изменений.
