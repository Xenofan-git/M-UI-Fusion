# M-UI Fusion 1.0.5 — Country flags in active balancers / Флаги текущих исходящих

## English

This UI maintenance release fixes the "Current outbound" column in both **Balancers from Outbounds** and **Balancers from Subscriptions**.

- Previously, the active member was prefixed with a Unicode regional-indicator emoji. On older Windows and Chromium versions, regional indicator emojis rendered as plain **LV/RU letters**, not flags.
- The active outbound now uses the **existing bundled SVG flag icons** from country-flags.js and flags/*.svg, the same asset system as subscription server lists. Flags are served locally, including behind a private panel URL.
- Duplicate provider and ISO country prefixes such as INT | lv and RU | ru are hidden from the **displayed label**. For example, INT | lv ... - Латвия now displays Latvia's SVG flag followed by ... - Латвия; similarly for Russia.
- UI updates use separate DOM nodes, never injected unescaped HTML. The original node name is retained in the tooltip.
- Dynamic Mihomo selection refresh and table redraw both preserve the flag icons. Unknown countries still display their server labels without an invented country flag.
- Added regression tests for Latvian, Russian and other country labels, original-name preservation, local flag assets, and correct active-selection rendering. A separate Chromium test confirmed both actual SVGs load and show clean labels.
- mihomo-settings.js and mihomo-settings.css use a new cache-busting URL (?v=105) for existing browser sessions.

**Scope: presentation only.** Mihomo server names, connection selections, balancing algorithms, 226 outbounds, routing rules, subscriptions, credentials, DNS, firewall, Tailscale and Keenetic configuration are not changed.

Before upgrading, back up the binary, state.json, and config.yaml. Earlier releases v1.0.0–v1.0.4 remain available.

## Русский

Исправлено отображение флагов в столбце **«Текущий исходящий»** на вкладках **«Балансировщики из Исходящих»** и **«Балансировщики из Подписок»**.

- Раньше вместо флагов использовались Unicode-эмодзи. На старых версиях Windows/Chromium они отображались как буквенные коды **LV/RU**, а не флаги.
- Теперь используются **локальные SVG-флаги** из уже существующего каталога flags/*.svg, как в списке серверов подписок. Они работают без обращения к внешним сайтам.
- Из отображаемого названия убираются дублирующиеся служебные и двухбуквенные префиксы: INT | lv, RU | ru и аналогичные. Вместо них появляется настоящий флаг страны.
- Полное имя сервера в конфигурации не меняется и доступно во всплывающей подсказке.
- При автоматическом переключении балансировщика и обновлении таблицы флаги сохраняются. Если страна не определяется, не показываем выдуманный флаг.
- Добавлены проверки для Латвии, России и других стран, сохранности исходного имени и локальных SVG. В Chromium реальные изображения Латвии и России успешно загрузились.
- Для обхода кэша обновлены ссылки на стили и скрипт (?v=105).

**Изменения исключительно визуальные.** Исходящие, правила маршрутизации, балансировщики, подписки, ключи, Tailscale, DNS и настройки Keenetic не меняются. Версии 1.0.0–1.0.4 сохранены.

Перед установкой создаётся резервная копия бинарника и файлов state.json, config.yaml.
