# M-UI Fusion 1.0.7 — Unified routing rule editor / Единое окно редактирования правил

## English

A usability update to the Mihomo routing rule editor. The **Mihomo engine and routing configuration are unchanged**.

All rule editors now use the same visible order: **Rule type → Conditions → Outbound → Advanced settings**. DIRECT, Russia and FOREIGN are outbound destinations, not different rule-editor modes.

- **Type** and **Conditions** are no longer hidden behind the Advanced settings accordion. Type help icons stay available.
- The Conditions area adapts to the chosen type without moving the other fields:
  - GEOIP,RU shows the country-code condition RU, with a label "Destination IP country".
  - DOMAIN, IP-CIDR, NETWORK, ports and other rule types show the appropriate condition label and their original editable expression.
  - List-based rules show the existing two columns for GeoSite/GeoIP categories and domains/IPs, with the category picker.
  - Complex raw AND rules, including rules routed to DIRECT, show their **original, unchanged logical expression**.
  - MATCH explicitly says it has no conditions; the outbound remains editable, while its type remains locked.
- The optional Advanced settings section now holds **No-Resolve only where applicable**. It can be expanded and collapsed normally.
- Switching types in the unsaved form does not erase the user's No-Resolve checkbox selection. Ineligible rule types cannot accidentally persist a No-Resolve value.
- All 33 existing rule type help explanations, the uppercase list label, country SVGs and previous visual styling are retained.
- Desktop and mobile Chromium regression tests cover existing GEOIP to Russia, raw AND to DIRECT, lists, MATCH to FOREIGN, new rules and type switching. Existing backend names, expressions and targets are not modified when the modal opens.

The panel's updated script, stylesheet and translation strings use ?v=107 to bypass stale browser caches.

**No migration.** The routing engine, current rule order, balancers, outbounds, subscriptions, credentials, DNS, firewall and Keenetic settings are untouched.

## Русский

Упрощено окно редактирования правил Mihomo. **Движок Mihomo и работающая маршрутизация не меняются.**

Теперь для всех правил один порядок полей: **Тип правила → Условия → Исходящий → Расширенные настройки**. DIRECT, Russia и FOREIGN — направления трафика, а не разные способы редактирования.

- **Тип правила** и **Условия** видны сразу, без открытия дополнительных настроек. Значки ! с пояснениями сохранены.
- Блок «Условия» подстраивается под выбранный тип:
  - GEOIP: поле кода страны, например RU, с понятным названием «Страна IP назначения».
  - DOMAIN, IP-CIDR, порты, протоколы и прочие типы: собственная подпись условия и прежнее редактируемое выражение.
  - Правила со списками: два поля GeoSite/GeoIP и домены/IP со справочником категорий.
  - Сложные AND, включая направленные в DIRECT: полное **исходное логическое выражение**, без автоматического изменения.
  - MATCH: надпись «Условий нет», возможность выбрать исходящий и защита типа правила от случайного изменения.
- В сворачиваемом разделе **«Расширенные настройки»** остаётся только No-Resolve там, где он применим.
- При смене типа в черновике состояние галочки не сбрасывается. Для типов, где опция не предусмотрена, она не записывается.
- Сохранены подсказки всех 33 типов правил, заглавная надпись «СПИСКИ КАТЕГОРИЙ, ДОМЕНОВ И IP», флаги и оформление.
- Тесты Chromium на ПК и мобильном экране проверяют существующие GEOIP в Russia, AND в DIRECT, списки, MATCH в FOREIGN, новые правила и смену типов.

Для браузеров обновлены адреса JS/CSS и переводов до ?v=107.

**Без миграции конфигурации.** Порядок правил, исходящие, подписки, балансировщики, ключи и настройки сети остаются прежними.
