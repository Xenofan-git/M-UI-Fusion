# M-UI Fusion 1.0.4 — Mihomo toolbar hover visibility / Исправлены кнопки маршрутизации и балансировщиков

## English

This patch addresses a remaining contrast defect in the **Routing Rules** and **Balancers from Outbounds** tabs reported after v1.0.3.

- Corrected four actual Mihomo toolbar action buttons: **Add Rule**, **Add Balancer**, **Add Outbound** and **Add Balancer from Subscription**. All now have a solid, readable background and matching foreground both at rest and on hover/focus. SVG icons inherit that same foreground.
- Added a reliable fallback without color-mix() or layered calc() CSS gradients for older browsers (including the Chromium generation available on Windows 8.1).
- Selected Graphite, Ivory, Emerald and Aurora skin accents are preserved. The standard Liquid Glass blue is adjusted only on these four toolbar actions to achieve WCAG AA text contrast.
- Explicit cache-busting for the changed color-skins.css asset on existing clients.
- Chromium tested the **real four HTML button elements** in 480 combinations: three UI themes × five skin choices (four named + default) × two light/dark states × two CSS compatibility modes × four buttons × normal/hover. **480 passed, zero failures**.
- Additional CI checks verify the exact button IDs and skin contrast.

**Scope:** purely visual. No Mihomo routing data, balancers, outbounds, subscriptions, login details or network settings were changed. Original releases v1.0.0–v1.0.3 remain available.

Back up the binary, state.json and config.yaml before updating.

## Русский

Это исправление устраняет оставшуюся после v1.0.3 ошибку контрастности кнопок во вкладках **«Правила маршрутизации»** и **«Балансировщики из Исходящих»**, обнаруженную пользователем.

- Исправлены **четыре реальные кнопки** панели Mihomo: «Добавить правило», «Добавить балансировщик», «Добавить исходящий» и «Добавить балансировщик из подписки». В обычном состоянии, при наведении и фокусе текст и значки теперь контрастны на сплошной цветной заливке.
- Добавлены стили, не зависящие от новых CSS-функций color-mix() и многослойных градиентов с calc(), для совместимости со старыми браузерами, включая поколение Chromium для Windows 8.1.
- Изумрудная, Графитовая, Аврора и Слоновая кость сохраняют свои цвета. Для исходной синей палитры Liquid Glass выбран более контрастный оттенок **только у четырёх кнопок**.
- Путь CSS-файла обновлён для обхода старого браузерного кэша.
- Проверка Chromium проведена **на самих четырёх HTML-кнопках**: 480 сочетаний тем, палитр, светлого/тёмного режима, совместимости CSS и состояния hover. **480 успешно, ошибок нет**.
- В CI добавлена проверка наличия конкретных элементов и контраста.

**Изменения только визуальные.** Исходящие, правила, балансировщики, подписки, ключи, маршрутизация Keenetic и Tailscale не затронуты. Предыдущие версии 1.0.0–1.0.3 сохраняются.

Перед обновлением требуется резервное копирование бинарника и файлов state.json, config.yaml.
