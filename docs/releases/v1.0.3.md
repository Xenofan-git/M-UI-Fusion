# M-UI Fusion 1.0.3 — Consistent button hover colors / Исправлено затемнение кнопок при наведении

## English

This visual maintenance release fixes buttons that unexpectedly became too dark, reverted to a different palette, or lost contrast when hovered.

- Fixed hover handling across **shadcn, Material Design 3, and Liquid Glass**, including normal light/dark mode and all **four** named color skins: Graphite, Ivory, Emerald and Aurora.
- The selected skin now consistently overrides dark-mode theme variables during mouse hover, not only at rest.
- Corrected ID-specific actions: **Add subscription balancer**, **Create/Save subscription balancer**, and **Add inbound**; updated main action buttons and inline icons to use the same foreground/background palette.
- Liquid Glass now preserves its layered glass effect while its surface buttons have a suitable hover tint.
- Added automated CI regression checks for the named palette hover colors and WCAG AA text contrast (at least 4.5:1); on the Moscow build machine, Chromium verified **120** concrete theme/skin/mode/action combinations successfully.
- No changes were made to the approved Emerald cat/logo, label wording, routing logic or stored network configuration.

**Safety:** Pure CSS/visual change. Outbounds, balancers, rules, subscriptions, credentials, DNS, firewall, Tailscale and Keenetic routing are untouched.

**Upgrade:** Back up m-ui, state.json and config.yaml before updating to v1.0.3. Existing releases v1.0.0–v1.0.2 and their changelogs are preserved.

## Русский

Выпуск исправляет кнопки, которые при наведении становились слишком тёмными, приобретали цвет другой темы либо теряли контрастность надписей и значков.

- Исправлены состояния наведения в **shadcn, Material Design 3 и Liquid Glass**, для светлого/тёмного режима и всех **четырёх** цветовых палитр: Графитовой, Слоновой кости, Изумрудной и Авроры.
- Выбранная цветовая палитра теперь сохраняется в тёмном режиме и при наведении курсора.
- Исправлены отдельные кнопки **«Добавить балансировщик из подписки»**, **«Создать/Сохранить балансировщик»** и **«Добавить входящий»**, а также основные кнопки действий и цвет их значков.
- Для Liquid Glass сохранён эффект многослойного стекла, а наведение на вспомогательные кнопки стало умеренным.
- Добавлены CI-тесты контрастности текста (минимум 4,5:1) и проверки CSS. В Chromium на московском VPS успешно проверены **120** сочетаний темы, палитры, режима и типа кнопки.
- Изумрудный котик, надписи интерфейса и маршрутизация остались прежними.

**Безопасность:** Исправления только визуальные. Исходящие, балансировщики, правила, подписки, ключи, DNS, firewall, Tailscale и настройки Keenetic не меняются.

Перед обновлением до v1.0.3 необходимо сделать резервную копию m-ui, state.json и config.yaml. Предыдущие релизы 1.0.0–1.0.2 остаются доступны.
